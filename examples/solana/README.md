# examples/solana — illustrative payloads

> **Illustrative only.** These JSON files are schema-valid examples written by hand to show the record formats. They are **not** real transactions, quotes or decisions, and contain no real user data. Token addresses marked EXAMPLE are placeholders. A runnable developer example is a grant milestone deliverable (M3).

Files
- execution-intent.json
- reconciliation-record-expired.json
- risk-decision-blocked.json

Validate against the schemas (Node 18+), from the repository root:

```sh
npm install
npm run validate:examples
```
